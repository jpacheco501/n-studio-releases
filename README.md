# N-Studio — versiones publicadas

Este repositorio solo contiene las **versiones compiladas** de N-Studio para
Windows 10/11 x64 (en *Releases*). N-Studio las consulta al iniciar para avisar
de actualizaciones.

- Cada versión es un `.zip` con el programa y un `.sig` con su firma. N-Studio
  solo instala una actualización si la firma es válida.
- **No incluyen firmware ni datos de ninguna calculadora.** Al primer inicio,
  N-Studio pide la BootROM y la flash de tu propia TI-Nspire CX II CAS.
- Al actualizar se conservan las carpetas `firmware` y `datos`.

N-Studio es una aplicación independiente de Texas Instruments. Incluye el motor
Firebird (GPLv3); las licencias van dentro de cada versión.
